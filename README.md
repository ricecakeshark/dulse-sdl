# Dulse-sdl

## Overview

Dulse-sdl is minimal wrapper of SDL3.

## Lisence

Mozilla Public License Version 2.0

## Require files

SDL3.dll
SDL3.lib
SDL3_image.dll
SDL3_image.lib
SDL3_mixer.dll
SDL3_mixer.lib
SDL3_ttf.dll
SDL3_ttf.lib

## Usage

dub.sdl
```SDL
dependency "dulse-sdl" version=">=0.0.0"
```

dub.json
```JSON
"dependencies":{
	"dulse-sdl":">=0.0.0"
}
```

import in D
```Dlang
import dulse_sdl;
```
